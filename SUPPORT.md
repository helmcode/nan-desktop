# Getting help

Pick the channel that matches your question; it gets you an answer faster.

| You want to... | Go to |
|----------------|-------|
| Ask how to use or build the app | [Discussions → Q&A](https://github.com/helmcode/nan-desktop/discussions/categories/q-a) |
| Propose or discuss an idea | [Discussions → Ideas](https://github.com/helmcode/nan-desktop/discussions/categories/ideas) |
| Report a bug in the app | [New issue → Bug report](https://github.com/helmcode/nan-desktop/issues/new?template=bug_report.yml) |
| Request a feature | [New issue → Feature request](https://github.com/helmcode/nan-desktop/issues/new?template=feature_request.yml) |
| Report a security vulnerability | **Privately**, following [SECURITY.md](SECURITY.md) |
| Join the NaN community, or a membership question | [nan.builders](https://nan.builders) (members: the community channels) |
| Helmcode enterprise account, organization, API keys or billing | [console.helmcode.com](https://console.helmcode.com) or **support@helmcode.com** |
| Download the app | [helmcode.com/es/download](https://helmcode.com/es/download) |

This repository's issues and discussions are for the **desktop app**.
Account, billing and membership questions cannot be solved here, and please
never post tokens, device codes or private conversation content in public.

Contributing code? See [CONTRIBUTING.md](CONTRIBUTING.md).
